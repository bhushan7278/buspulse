# BusPulse Frontend (Admin Dashboard)

This is the admin and operator panel for the **BusPulse** smart transport management system. It is used exclusively by depot staff and operators to manage drivers, dispatch trips, check driver attendance, monitor live routes, and evaluate passenger demand.

> [!NOTE]
> This is an internal administrative utility. There is no public passenger-facing app in the codebase.

## Getting Started

1. **Install Dependencies:**
   ```bash
   npm install
   ```

2. **Run in Development Mode:**
   ```bash
   npm run dev
   ```

3. **Build for Production:**
   ```bash
   npm run build
   ```
